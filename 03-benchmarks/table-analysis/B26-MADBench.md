# B26 MADBench — 数据表格与分析

> 论文：MADBench: Benchmarking the Security of Multi-Agent Debate  
> 表格：[analysis/tables](../B26-madbench/analysis/tables/)  
> 数据集状态：**无公开数据或代码**，以下为论文数据。

## 1. 设计

针对“多智能体辩论”（MAD）架构：5 个辩论智能体 + 1 个编排者（默认 gpt-4o，1 轮辩论）。356 个源任务（SealQA 100、StrategyQA 100、AgentDojo 工作区 56、JailbreakBench 100）生成 3,958 个测试用例。6 类攻击覆盖输入层、环境层、资源层、智能体层、编排者层（`paper_T1_attack_families.csv`）。指标：ASR、IRW（越权读写率）、Cost（被攻击/干净运行 token 比）。

## 2. 辩论是“吸收”还是“放大”攻击？（Table 2，放大系数 AF）

AF = MAD 下指标 / 单智能体指标，>1 表示放大。

| 攻击 | 目标 | ASR AF | IRW AF |
| --- | --- | --- | --- |
| M1 越狱 | 有害回答 | 0.88（略吸收） | – |
| M2 工作区间接注入 | 越权读取 | **3.09** | 1.93 |
| M2 | 成本攻击 | 1.60 | **3.00** |
| M3 RAG 投毒（问答） | 准确性 | 0.74（吸收） | ∞ |
| M4 | 越权读取 | 0.00 | 1.02 |

- **问答任务上辩论能吸收攻击**：编排者会比对各方证据，3/5 被投毒的智能体也不一定能左右最终答案（案例 A）。
- **工作区任务上辩论放大攻击**：M2 在 12 项比较中有 11 项被放大。案例 B：单智能体只读了恶意账单文件但没付款；辩论中两个智能体建议付款，讨论后五个全部同意，最终执行了越权支付。
- 即使问答准确性被吸收，越权读写仍会被放大（IRW 出现 ∞，即单智能体为 0 而 MAD 非 0）。

## 3. 被攻陷的辩论成员与编排者（Table 4）

| 模式 | f=3 时 ASR | IRW |
| --- | --- | --- |
| 合谋（统一错误答案） | **28.30** | 49.00 |
| 各自独立 | 11.32 | 52.00 |
| 不一致（对不同人说不同话） | 5.66 | **74.00** |
| 编排者被攻陷（M6） | **100** | **100** |

- 合谋最能左右答案；“不一致”模式答案影响最小，但越权操作最多（编排者在收尾时擅自写文件）。
- 诚实智能体很少被带偏：最初答对的诚实智能体中最多 3.26% 在辩论中改错（`C2W`）。
- 换更强模型显著提升抵抗力（Table 4b）：GPT-5 ASR 6.9%、GPT-6 Astra 3.28%。
- 增加辩论轮数无明显改善（Table 10：R=1/2/3 的 ASR 为 28.30/26.92/33.33）。
- **编排者是单点故障**：一旦被攻陷，ASR 与 IRW 都是 100%，token 成本放大到 181%。

## 4. 展示建议

放大系数热力图（Table 2）与“合谋/独立/不一致/编排者”四种攻击模式的对比柱；强调“多智能体≠更安全，取决于任务类型”。
