# B08 Agent-SafetyBench — 数据表格与分析

> 论文：Agent-SafetyBench: Evaluating the Safety of LLM Agents（清华 CoAI）  
> 表格：[analysis/tables](../B08-agent-safetybench/analysis/tables/)

## 1. 数据集结构（由 released_data.json 统计）

- 2,000 条用例，8 类风险各 250 条；使用 349 个不同模拟环境（与论文一致）；111 条带预置对话历史。
- 行为类 vs 内容类（`data_risk_x_behavior_content.csv`）：1,589 条需要工具环境（行为安全），411 条无环境（内容安全）。“Produce unsafe information” 250 条全部是纯内容；“Harmful code” 有 158 条是纯内容；其余 6 类几乎全是行为类。
- 可完成性（`data_risk_x_fulfillable.csv`）：735 条（36.8%）是“可以安全完成”的任务，1,265 条应当拒绝或无法安全完成。“Produce” 全部不可完成，“Compromise availability” 正好 125/125。这个标注用于区分“靠拒绝换安全”和“正确完成任务的安全”。
- 失效模式（`data_failure_mode_counts.csv`，多标签共 2,294 次）：M5 忽视隐含风险 421、M1 直接生成有害内容 392、M9 过度信任工具结果 358、M4 忽视明确约束 333、M2 信息不全即调用 257；M3、M8 最少（77、79）。
- `data_environment_usage.csv` 列出 349 个环境各被多少用例使用；论文 Table 2 把环境分为 4 级“现实性”：已有基准中出现 68、有公开 API 无沙盒 42、暂无 API 但有现实应用 220、未来设想类 19。

完整 16 行 × 11 列见 `paper_T5_safety_scores_by_risk.csv`。

- **没有任何模型超过 60%**。Claude 系列明显领先，开源模型普遍 20–37%。
- 行为安全远差于内容安全（平均 30.4 vs 68.4）：模型已经学会拒绝写有害内容（Produce 平均 87%，Claude 100%），但在调用工具做事时不会判断风险。
- 最难的类别是 “Spread”（平均 15.6%）：智能体很容易不加核实地通过发帖、邮件传播不安全信息。
- GLM4-9B 是特例：总分 36.5 中行为分 34.6 反而接近内容分 44.3，可用性类别 50.8% 为全表最高。

## 3. 按失效模式（Table 6）

`paper_T6_safety_scores_by_failure_mode.csv` 平均：M1 70.1、M6 63.3、M10 63.1 较好；**M7 仅 12.5、M2 18.1** 最差——模型会无视工具上标注的“未验证/有问题”而照样调用，也会在信息不足时自行编造参数。GPT-4o-mini 在 M7 上只有 2.3%，Llama3.1-8B 0.8%。

## 4. 其他结论

- Figure 3（无数值表）：强模型在可完成任务上同样有用，在不可完成任务上有用率明显更低——它们的安全来自正确判断，而非一律拒绝。
- Figure 4（无数值表）：加入列举失效模式的防御提示，对弱模型无效，对强模型有限提升，Claude-3.5-Sonnet 仍低于 70%。
