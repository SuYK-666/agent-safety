# B04 Agent Red Teaming (ART) — 数据表格与分析

> 论文：Security Challenges in AI Agent Deployment: Insights from a Large Scale Public Competition（Gray Swan × UK AISI）  
> 表格：[analysis/tables](../B04-agent-red-teaming/analysis/tables/)  
> 数据集状态：**无公开测试集**。ART 的 4,700 条攻击作为私有排行榜保留，本目录只有论文数据。Figure 3、Figure 5 的数值是我把 PDF 页面渲染成图后逐格读出的（图上印有数值标签），已与文本层交叉核对。

## 1. 规模（`paper_text_key_numbers.csv`）

2025-03-08 至 04-06 的公开竞赛：约 2,000 名参赛者、约 180 万次攻击尝试、6.2 万余次成功违规，覆盖 22 个前沿模型、44 个部署场景（4 类行为：机密泄露、目标冲突、违禁信息、违禁动作）。每个模型在每个行为上都至少被攻破过一次（行为级 ASR 100%）。从中筛出 ART 基准：44 行为 × 每模型最多 5 条 = 4,700 条高质量攻击，评测 19 个模型。

## 2. 按类别与攻击向量（Table 1，会话级 ASR）

| 类别 | 直接 | 间接 | 全部 |
| --- | --- | --- | --- |
| 机密泄露 | 7.8 | 29.8 | 17.1 |
| 目标冲突 | 7.0 | – | 7.0 |
| 违禁内容 | 4.8 | 15.9 | 8.9 |
| 违禁动作 | 4.2 | **36.8** | 15.9 |
| 全部 | 5.7 | 27.1 | 12.7 |

间接注入的会话成功率是直接攻击的 4.8 倍；“通过第三方数据诱导智能体执行违禁动作”最危险（36.8%）。

## 3. 各模型竞赛 ASR（Figure 3）

`paper_F3_challenge_asr_by_model.csv`：最高 Llama 3.3 70B 6.7%、Pixtral Large 6.1%、Llama 3.1 405B 5.9%；最低为 Anthropic 系列（3.5 Haiku 2.4%、3.5 Sonnet 1.9%、3.7 Sonnet 1.7%、3.7 Sonnet:Thinking 1.5%）。注意这是“所有会话”的比例，数值低是因为分母包含大量失败尝试；o3 进场较晚，其 2.9% 可能偏高。

## 4. 迁移攻击矩阵（Figure 5，14×14）

`paper_F5_transfer_matrix.csv` 为原矩阵，`paper_F5_transfer_long.csv` 为长表（便于做热力图）。我额外计算了 `derived_F5_transfer_summary.csv`（非对角均值）：

| 模型 | 作为目标被迁移攻击的平均 ASR | 作为来源的平均迁移率 |
| --- | --- | --- |
| Llama 3.3 70B | **53.5**（最脆弱） | 15.0（攻击最难迁移出去） |
| o3 Mini:High | 43.3 | 29.5 |
| o3 Mini | 42.3 | 27.2 |
| Llama 3.1 405B | 39.8 | 22.8 |
| … | | |
| 3.7 Sonnet:Thinking | 15.4 | **38.1**（攻击最强） |
| o3 | **15.3**（最稳健） | 37.5 |

- 结论与论文一致：在稳健模型上打通的攻击迁移性更强（o3、3.7 Sonnet:Thinking 作为来源平均 37–38%）；弱模型几乎被所有来源的攻击打穿。
- 同家族互相迁移高：o3 Mini → o3 Mini:High 59%，GPT 4o → GPT 4.5 38%。
- 对角线（在原目标上复测）只有 31–60%，说明竞赛中成功的攻击在重放时也并非稳定复现（模型随机性/截断方式）。

## 5. 其他发现

- 能力与稳健性相关性弱：迁移 ASR 与 GPQA 相关系数 −0.31；发布时间与 ASR 几乎无关（Figure 9）。
- 推理算力不一定带来稳健：3.7 Sonnet 开启思考略有改善，o3-mini 高推理档几乎无改善。
- ART 上 1 次查询即可让 20–60% 的行为违规，10 次查询后大多数模型接近 100%（Figure 4 仅有柱状图，未印数值，未转录）。
