# B40 METR Time Horizons — 数据表格与分析

> 论文：Measuring AI Ability to Complete Long Software Tasks（METR, 2025-03）  
> 表格：[analysis/tables](../B40-metr-time-horizons/analysis/tables/)  
> 定位：**自主能力趋势**基准（任务本体大多私有，公开的是逐次运行结果），在展示系统中用于说明“智能体能自主完成多长的任务”，是风险评估的背景指标。

## 1. 数据（`data_v1_*_overview.csv`）

- Time Horizon 1.0：41,629 次运行、33 个模型。
- Time Horizon 1.1：24,008 次运行、20 个模型、228 个任务（HCAST 157、SWAA 66、RE-Bench 5），79 个任务族；人类完成时间从约 1 秒到 30 小时。
- 任务长度分布（v1.1，`data_v1_1_tasks_by_length_x_source.csv`）：<1 分钟 69（全部为 SWAA 原子动作）、4–15 分钟 38、15–60 分钟 36、1–4 小时 22、4–16 小时 46、>16 小时 4。
- `data_v1_*_success_by_model_x_length.csv`：每个模型在各时长区间的平均成功率，可直接画“成功率随任务时长衰减”的曲线。

## 2. 核心指标：50% / 80% 时间跨度（`results_model_horizon_summary.csv`，METR 官方发布）

“时间跨度”= 模型有 50%（或 80%）把握完成的任务，相当于人类专家要花多少分钟。

| 模型 | 发布 | 50% 跨度 | 80% 跨度 |
| --- | --- | --- | --- |
| GPT-2 | 2019-02 | 0.05 分钟 | 0.01 分钟 |
| GPT-4 | 2023-03 | 4.0 分钟 | 0.9 分钟 |
| Claude 3.5 Sonnet (新) | 2024-10 | 20.5 分钟 | 2.6 分钟 |
| o1 | 2024-12 | 38.8 分钟 | 7.1 分钟 |
| Claude 3.7 Sonnet | 2025-02 | 60.4 分钟 | 12.1 分钟 |
| o3 | 2025-04 | 119.7 分钟 | 30.0 分钟 |
| GPT-5 | 2025-08 | 203 分钟 | 38.3 分钟 |
| Claude Opus 4.5 | 2025-11 | 293 分钟 | 49.4 分钟 |
| Claude Opus 4.6 | 2026-02 | 719 分钟 | 69.9 分钟 |
| Claude Mythos Preview | 2026-04 | **1,045 分钟（约 17 小时）** | 186 分钟 |

（完整 26 个模型及 95% 置信区间见 CSV。）

- 论文结论：50% 时间跨度约每 7 个月翻一番（207 天）；80% 跨度的翻倍速度相近（204 天），但绝对值短 4–6 倍——**模型偶尔能做成长任务，但稳定完成中等长度任务的能力要弱得多**。最新数据显示 50% 与 80% 跨度的差距仍在拉大（Opus 4.6 为 10 倍）。
- 置信区间很宽（如 Claude 3.5 Sonnet 6 月版 50% 跨度 11.4 分钟，CI 5.5–22.4），横向比较需谨慎。

## 3. 论文附表

- Table 7：按任务来源的成功率——SWAA 几乎都 ≥95%，HCAST 0.23–0.65，RE-Bench 最难（o3 0.40，其余 ≤0.27）。
- Table 9：同一模型在 METR 任务与 SWE-bench Verified 上测得的时间跨度相差 0.8–7.8 倍，弱模型在 SWE-bench 上显得更差。
- Table 2：失败原因从“重复失败动作”（GPT-4）转向“过早放弃任务”（o1，16/32）。

## 4. 展示建议

发布时间 × 50% 跨度的对数坐标散点 + 指数拟合线，是这个基准的标志图；可与安全基准中“能力越强 ASR 越高”的现象（B01、B03）呼应。
