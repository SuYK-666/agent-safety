## 2. 主结果：15 个模型 × 3 种攻击设置（公开测试集，Table 9）

`derived_T9_pivot_by_model.csv`：

| 模型 | 无攻击 伤害分 / 拒绝率 | 强制工具调用 伤害分 | 越狱模板 伤害分 / 拒绝率 | 良性得分 |
| --- | --- | --- | --- | --- |
| Mistral Large 2 | 82.2 / 1.1 | 80.9 | 80.5 / 0.0 | 77.7 |
| Mistral Small 2 | 72.0 / 7.2 | 73.7 | 72.7 / 0.8 | 71.8 |
| GPT-4o mini | 62.5 / 22.0 | 68.4 | 68.8 / 2.3 | 79.9 |
| GPT-3.5 Turbo | 62.2 / 0.8 | 63.2 | 62.0 / 0.4 | 67.7 |
| GPT-4o | 48.4 / 48.9 | 57.7 | 72.7 / 13.6 | 89.9 |
| Claude 3.5 Sonnet | 13.5 / 85.2 | 26.9 | **68.7 / 16.7** | 82.0 |
| Claude 3 Haiku | 11.1 / 83.7 | 33.9 | 6.6 / 90.5 | 67.7 |
| Gemini 1.5 Pro | 15.7 / 78.4 | – | 56.1 / 3.5 | 64.6 |
| Llama-3.1 405B | 4.3 / 91.2 | – | 4.3 / 92.0 | 38.6 |

分析：

- **不越狱时很多模型就会照做**：Mistral 系列和 GPT-3.5 Turbo 拒绝率不到 8%，伤害分 62–82%；GPT-4o mini 拒绝 22%。
- **一个简单的通用越狱模板就能大幅瓦解拒绝**：Claude 3.5 Sonnet 伤害分 13.5% → 68.7%，拒绝率 85.2% → 16.7%；Gemini 1.5 Flash 拒绝率 69.2% → 1.8%；GPT-4o 48.4% → 72.7%。
- 越狱后智能体能力基本保留：Claude 3.5 Sonnet 越狱后的非拒绝伤害分 81.9%，与其良性得分 82.0% 几乎相同——即“被越狱的智能体”能像正常任务一样高质量地完成多步有害任务，这是比聊天越狱更严重的风险。
- 例外：Claude 3 Haiku 和 Llama-3.1 405B 对该模板几乎免疫（拒绝率 90%+），但 Llama 405B 良性得分也只有 38.6%。
- `paper_T10_private_test.csv`（私有测试集，7 个模型）趋势一致，如 Claude 3.5 Sonnet 无攻击 12.0% → 模板 68.9%。

## 3. 消融

- `paper_T2_best_of_n.csv`：温度 1 下采样 5 次取最好，GPT-4o 伤害分升到 83.7%，Mistral Large 2 达 90.8%。
- `paper_T3_prompting.csv`：在系统提示中加入“拒绝提示”是唯一有效的提示层防御——GPT-4o 无攻击伤害分降到 16.6%、模板攻击下降到 9.5%；但对 Mistral Large 2 + 模板几乎无效（79.5%）。CoT/ReAct 对伤害分影响不大。
- `paper_T8_agent_vs_chat_refusal.csv`：同样的有害请求，以“智能体任务”形式提出时拒绝率系统性低于纯聊天形式（GPT-4o 50.0% vs 72.7%；模板攻击下 Claude 3.5 Sonnet 29.5% vs 72.7%）——**聊天场景的安全训练没有完全迁移到工具调用场景**。
